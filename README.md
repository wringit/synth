# Python Synth

Python music software for creating music. Very incomplete. 

# Running

Right now, the only way you can really run it is by changing the array of notes in song.py. As it is, it generates Mary's Lamb Died (Mary Had a Little Lamb in c minor). You can also change the sin_oscillation to `triangle_oscillation`, `square_oscillation`, or , `sawtooth_oscillation`.

I also recommend writing in the key of C and keeping notes to one octave (unless you modify the other files). If you leave the octave (starting from C and ending with B), it will wrap around to the note in the octave that I have set it to write in.

Also, you can't change the length or rhythm of notes yet. Songs may take a very long time to generate.
